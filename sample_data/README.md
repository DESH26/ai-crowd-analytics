# Sample Data Directory

This directory stores aerial video clips and benchmark sequences used for testing and validating the AI Crowd Analytics pipeline.

## Default Sample Clip: `aerial_sample_preview.mp4`
- **Resolution:** 768 x 432
- **Frame Rate:** 12.0 FPS
- **Duration:** 53.9 seconds (647 frames)
- **Pedestrians:** Multiple pedestrians traversing the scene with bidirectional movement.
- **License / Source:** Permissively licensed public open-source benchmark video (Intel IoT DevKit Computer Vision benchmark repository).

## Adding Custom Aerial Videos
Users and evaluators from Susan Future Technologies (SFT) can place custom drone or aerial video footage (e.g., VisDrone, UAVDT, or recorded aerial surveillance) directly into this folder or upload via the Streamlit web dashboard.
Supported formats: `.mp4`, `.avi`, `.mov`, `.mkv`.
